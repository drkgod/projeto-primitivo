# Orientações de execução do Radar Primitivo

Antes de selecionar a próxima tarefa ou responder ao Leonardo, ler `.adapta-cliente/comunicacao-com-leonardo.md`, `.adapta-cliente/estado-atual.md` e os aceites mais recentes. A comunicação deve ser compreensível sem conhecimento técnico.

Reaproveitar decisões confirmadas. Não condicionar a construção independente a um formulário ou a uma autorização genérica. Executar uma tarefa disponível por vez, registrar as provas e continuar pelas dependências. Uma informação faltante bloqueia somente o uso que depende dela.

As explicações de negócio no início das oito especificações orientam a conversa com Leonardo; o restante de cada especificação orienta a implementação e os testes do Maestro. Preservar os contratos, critérios de aceite, IDs e requisitos para gasto, fonte e dados reais. Não usar linguagem simples para omitir uma decisão real necessária.

Atualização documental não comprova execução do app nem aciona, por si só, uma sessão no Skip. Não declarar início, conclusão, publicação, teste ou aprovação sem evidência.
